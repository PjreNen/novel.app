##アプリについて
コマンド保存できる小説等を書くためのアプリ

##目的
現在ある物書きのappの機能が使いにくいものが多いため使用者の使う文字列を保存して、設定したキー入力で呼び出せる機能のあるリッチエディター。
また現在ある多くのappがサーバー保存であり、一定数それを懸念する層がいるため、ローカル保存であること。

##使用技術
- React
- TyoeScript
- HTML / CSS
- React Hooks（useState, useEffect,useRef）
- Context API（状態管理）
- React Router（画面遷移）
- contenteditable（インライン編集機能）
- localStorage（データ保存）
- Node.js

##機能
簡易的な機能に加えて、F1ーF12までに、記憶させた文字列を呼び出せます
また保存は自動保存です
