##アプリ概要
小説執筆向けのリッチテキストエディタ。
ユーザーが登録した定型文を、キーボード操作（F1〜F12）で瞬時に呼び出せる。

##開発背景・目的
既存の執筆アプリは以下の課題
定型文入力が面倒
クラウド保存が前提で不安を感じるユーザーが一定数
なので
ローカル保存
ショートカットで定型文呼び出し
を軸に開発した。

##主な機能
リッチテキスト編集（contenteditable）
定型文の登録・呼び出し（F1〜F12）
$0によるカーソル位置制御
自動保存（localStorage）
ページ管理（作成・削除）

##技術構成
React / TypeScript
Context API（状態管理）
React Router（画面遷移）
contenteditable（エディタ実装）
localStorage（データ保存）
Node.js（開発環境）

##工夫した
contenteditableを用いたエディタ実装
キー入力イベントによる高速な定型文挿入
カーソル位置制御（$0）
